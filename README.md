# 🗂️ Task Management Platform

A scalable and modern **Task Management Platform** built using **Spring Boot**, designed to help teams and individuals efficiently manage tasks, track progress, and improve productivity. The system supports authentication, role-based access, activity logging, and modular architecture suitable for microservices.

---

## 🚀 Features

### 🔐 Authentication & Authorization
- Secure user registration and login
- JWT-based authentication
- Role-based access control (Admin, Manager, User)

### 📝 Task Management
- Create, update, delete tasks
- Assign tasks to users
- Set deadlines, priorities, and statuses
- Add detailed descriptions and attachments

### 📊 Productivity Insights
- Dashboard with task summaries
- Activity logs for tracking changes
- Filters for status, priority, assignee, and date

### 📦 Architecture
- Spring Boot backend with modular services
- Separation of Auth, Task, and Analytics services
- Prepared for microservice expansion

---
